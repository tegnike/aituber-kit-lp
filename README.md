# AITuberKit LP（ランディングページ）

[AITuberKit](https://github.com/tegnike/aituber-kit) の公式ランディングページです。

公開URL: [https://promotion.aituberkit.com](https://promotion.aituberkit.com)

## 技術スタック

- React 19 + TypeScript
- Vite 7
- Tailwind CSS 4

## セクション構成

| セクション | 内容 |
|-----------|------|
| Hero | メインビジュアルとキャッチコピー「あなただけのAIキャラクターを、すぐに。」 |
| Use Cases | 6つの活用シーン（YouTube配信、展示会・イベント、カフェ、自動おもてなし、プレゼン、オリジナルキャラ） |
| Characters | 3種類のキャラクターモデル紹介（VRM / Live2D / PNGTuber）※動画付き |
| AI Specs | 対応AIプロバイダー（16種類）と音声合成エンジン（11種類）の一覧 |
| Languages | 16言語対応の表示 |
| Setup | 4ステップのクイックスタート手順 |
| CTA | GitHubリンクと商用ライセンス案内 |

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

ビルド成果物は `dist/` に出力されます。
